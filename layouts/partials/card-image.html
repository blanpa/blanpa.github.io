{{- /* Resolve a page's card image URL: first image resource matching feature, cover, or thumbnail, resized to the given width. SVGs and sites with image optimization disabled pass through unresized. Returns "" when the page has no matching image. Params: page, width (int). Callers put class="nozoom" on the . Image zoom is off site-wide (disableImageZoom in params.toml, which only works because layouts/partials/footer.html forks the theme's broken condition), so nothing depends on the class today. It stays because covers are never what a reader wants to enlarge: if zoom is ever switched back on for a real in-article illustration, the covers are already excluded. */ -}} {{- $url := "" -}} {{- $images := .page.Resources.ByType "image" -}} {{- $img := "" -}} {{- range slice "*feature*" "*cover*" "*thumbnail*" -}} {{- if not $img }}{{ $img = $images.GetMatch . }}{{ end -}} {{- end -}} {{- with $img -}} {{- if or (site.Store.Get "disableImageOptimization") (eq .MediaType.SubType "svg") -}} {{- $url = .RelPermalink -}} {{- else -}} {{- $url = (.Resize (printf "%dx" (int $.width))).RelPermalink -}} {{- end -}} {{- end -}} {{- return $url -}}
